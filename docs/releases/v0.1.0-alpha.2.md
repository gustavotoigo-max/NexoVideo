# NexoVideo 0.1.0-alpha.2

Pré-release para testar o fluxo de reprodução e avaliação no outro computador.

- Dois cliques no arquivo em **Análise** ou **Relatórios** abrem o original no player padrão do Windows.
- A tela de Relatórios prepara a avaliação do mesmo arquivo; também há botão para abrir o selecionado.
- Ao salvar, a avaliação é persistida com conferência de SHA-256. O avanço opcional seleciona o próximo arquivo, inclusive entre páginas.
- O próximo vídeo não inicia automaticamente. Notas, veredito e confirmações são limpos ao trocar de arquivo; avaliador e player são mantidos.
- A solicitação de abertura fica no histórico; não é usada como prova de reprodução, tempo assistido ou avaliação satisfatória.
- Relatórios locais `NexoVideo-sessao-*.json` são ignorados pelo Git.

## Instalar no PC de testes

Feche a versão anterior e execute **NexoVideo-0.1.0-alpha.2-win-x64-Setup.exe**, usando a mesma conta Windows.
Dados e ferramentas já preparados são reutilizados. Confira `0.1.0-alpha.2` na barra superior.
O ZIP portátil é a alternativa: extraia a pasta inteira em um novo local.

.NET 10.0.13 incluído. Para o primeiro uso, prepare FFmpeg em Configurações; isso não é necessário novamente se os caminhos existentes continuarem válidos.

## Verificação e limites

27 testes automatizados, incluindo o fluxo WPF de abrir, salvar e avançar entre páginas com 101 arquivos sintéticos.
O teste usa um lançador simulado para não abrir players reais nem acessar os dados do usuário.
Os testes de instalação, execução do pacote e integridade constam no anexo `VALIDACAO-RELEASE.json`.

Mantém os limites da alpha.1: Windows x64, versão sem assinatura digital, recuperação experimental e homologação de corpus real em andamento.
