# NexoVideo 0.1.0-alpha.3

Remoção da avaliação manual por vídeo para preparar testes em lote com uma referência gerada pelo corruptor.

- Removidos formulário, notas/veredito humano, abertura de player para avaliação e avanço após salvar.
- Removido o cálculo de comparação baseado em avaliações individuais.
- Relatórios passam a concentrar a exportação das evidências de toda a sessão.
- Mantidos SHA-256, diagnósticos por arquivo/trilha/trecho, estados de execução, comandos e logs.
- Novo schema `nexovideo.evidence/2`, com comparação externa explicitamente não realizada.
- Avaliações antigas preservadas no banco e no campo opcional `legacy_review_history` do relatório, sem classificação ativa.

## Usar no PC de testes

Feche a versão anterior e execute **NexoVideo-0.1.0-alpha.3-win-x64-Setup.exe** na mesma conta Windows.
O instalador reutiliza a pasta de dados e as ferramentas existentes. Confira `0.1.0-alpha.3` na barra superior.
O ZIP portátil é a alternativa sem instalador; extraia a pasta inteira em um novo local.

Execute a análise em lote e exporte o JSON em **Relatórios**. A comparação com a lista do corruptor fica para a próxima etapa;
não foi introduzido importador nem formato presumido para essa referência.

Mantidos .NET 10.0.13 incluído, alvo Windows x64, ausência de assinatura digital e recuperação experimental.
O anexo `VALIDACAO-RELEASE.json` registra testes e verificação dos pacotes.
